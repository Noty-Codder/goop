## Features
Premium photo player panel, autoplay, playlists, VC logger, link / bio remover with approve list, daily 24h report (`/data`, `/bdata`, 7 AM IST), self promo (`/selfpromo run`), small-caps UI.

## Deploy
See [DEPLOY.md](DEPLOY.md) for Heroku, Railway and VPS. Variables are listed in `sample.env`.

```
git clone https://github.com/TEAM-ISTKHAR/IstkharMusic
cd IstkharMusic && cp sample.env .env && nano .env
./deploy/vps.sh
```
